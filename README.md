# Лабораторная работа №1: Основы 3D-графики

**Вариант 4:** усечённый правильный тетраэдр (грани - правильные треугольники и шестиугольники).

Программа написана на C++20 с использованием Vulkan, GLFW и ImGui.

## Что сделано

- Фигура отрисовывается в реальном времени с тестом глубины.
- Переключение перспективной и ортографической проекции.
- Изменение позиции, поворота и растяжения фигуры через интерфейс.
- Движение по траектории с собственным вращением. Есть пауза, перезапуск, скорость, радиус и высота траектории.
- Изменение цвета фигуры через `ColorEdit`.
- Цвета вершин считаются из их позиции в локальной системе координат. Выбранный в интерфейсе цвет умножается на них.

## Как собрать

Нужны: компилятор с поддержкой C++20 (GCC 10+ или MSVC), CMake, Vulkan SDK (`glslc` должен быть в PATH).

```
git clone https://github.com/Valeria115/vulkan-starter-app.git
cd vulkan-starter-app
git switch lab1
cmake --preset mingw-debug
cmake --build build-debug --parallel
```

Для Visual Studio вместо `mingw-debug` используется пресет `msvc-debug`.

## Как запустить

Запускать нужно из корня проекта:

```
.\build-debug\vulkan-starter-app.exe
```

Для сборки через Visual Studio файл лежит в `build-debug\Debug\`.

## Где что лежит

- `source/application.cpp` — код лабораторной (фигура, матрицы, интерфейс, отрисовка).
- `shaders/tetra.vert`, `shaders/tetra.frag` — шейдеры.
- `CMakeLists.txt` — сборка (добавлены библиотека GLM и компиляция шейдеров).
